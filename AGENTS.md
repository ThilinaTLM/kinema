# AGENTS.md

- Pre-1.0 personal project: refactor freely, prefer clean rewrites over compatibility shims, and do not add migrations for `~/.config/kinemarc`, `kinema.db`, or keyring entries.
- `src/CMakeLists.txt` lists sources and QML explicitly. Add new C++ files to `kinema_core_SRCS`; add app QML to the `dev.tlmtech.kinema.app` `QML_FILES`; keep embedded-player sources/QML under `if(KINEMA_ENABLE_MPV_EMBED)`.
- Object ownership: use `std::unique_ptr` for `app::ServiceContainer`-owned long-lived services; use QObject parent-ownership (`new T(parent)`) for everything with a natural QObject parent. Don't mix the two models for the same object.
- Composition lives in `app::ServiceContainer` (plain C++ in `src/app/`); it owns every long-lived service and page view-model and parents the QObjects to an internal anchor so destruction order matches construction. Construction is grouped into `buildInfrastructure()` / `buildRepositories()` / `buildPlaybackSubsystem()` / `buildControllersAndViewModels()` / `wirePresentation()` — keep new wiring in the matching phase.
- The movie and series detail pages share `kinema::ui::qml::DetailViewModelBase` (`src/ui/qml-bridge/DetailViewModelBase.{h,cpp}`): meta block, stream UI-filters + sort, debrid chip, the "More like this" rail, library state, and every per-row stream action live there once. Put only kind-specific state in the subclass (movie: runtime/upcoming + movie watched; series: seasons/episodes + series watched). Subclasses implement the pure-virtual `mediaKind()` + `currentContext()`. The `MetaState` enum + `metaState`/`metaError` stay on each subclass so QML's `MovieDetailViewModel.Ready` attached-enum lookup resolves on the registered type. The QML shell view-model is `ui::qml::ShellViewModel`, exposed to QML as the `shell` context property. Engine wiring (image provider, context properties, `KLocalizedContext`) is centralized in `ui::qml::installQmlContext()` (`ui/qml-bridge/QmlContext.{h,cpp}`). Put page state and page slots in per-page view-models under `src/ui/qml-bridge/`. Settings VMs live in `src/ui/qml-bridge/settings/` under the `kinema::ui::qml::settings::` namespace, one VM per file.
- Store TMDB, Real-Debrid, and OpenSubtitles credentials only through `controllers::TokenController` + `core::TokenStore` (system keyring). Never persist credentials in `KSharedConfig`.
- `config::AppSettings` owns `KSharedConfig`; read/write KConfig only inside `src/config/`. Inject settings objects instead of adding a global config singleton.
- Guard async UI/controller requests with an epoch counter, and translate thrown failures with `core::describeError(e, "context")` from a single `catch (const std::exception&)`.
- Route clipboard, external-player, URL-open, and play actions for `domain::Stream` through `services::StreamActions`; QML stream cards call detail-page view-model slots.
- Per-row stream-picker hints (source / codec / HDR / audio / language / release-group / pack classification) all live in `core::stream_tokens` (`src/core/util/StreamTokens.{h,cpp}`); the streams `QAbstractListModel` exposes them through named roles (`source`, `codec`, `hdr`, …, `packKind`, `packLabel`, `packClaim`). `core::stream_tokens::classifyPack` is series-only — movie pages must leave `StreamsListModel::setMediaKind` at its `Movie` default so the "Season pack" chip stays hidden there. Embedded auto-next-episode is wired through `controllers::SeriesPlaybackSessionController` (under `KINEMA_HAVE_LIBMPV`): it derives prev/next from the active session's file list and emits `packAdjacencyResolved(...)` so the shell can surface a one-shot passive status when a pack actually carries the next episode, plus `currentStreamSizeResolved(...)` so the picker row whose original parse left the size cell blank gets patched in place via `StreamsListModel::hydrateSize`.
- Per-file byte size on stream rows comes from a three-tier fallback chain in `api::stremio::parseStreams`: top-level `sizebytes` (Peerflix), then `behaviorHints.videoSize` (Stremio spec), then the `\xf0\x9f\x92\xbe N GB` emoji regex (Torrentio). The active session's authoritative size hydrates the picker row at playback time (see above).
- Magnet file lists are surfaced through a unified `playback::sources::AssetSession::files()` API: `TorrentAssetSession::files()` forwards to `torrent::TorrentStreamingService::filesForInfoHash`, `HttpRangeAssetSession::files()` returns the list the debrid resolver cached on first `ensureResolved()`. Both Real-Debrid and AllDebrid resolvers populate `ResolvedDebridLink.files` with positional 0-based indices so callers don't need to know about provider id quirks. Callers that only know an info hash should go through the unified `playback::ports::SessionFileCatalog` (implemented by `playback::transfer::SessionRegistry`; surfaced via `playback::transfer::TransferUseCase::filesForStreamRef` / `filesForAssetId`) — it walks active sessions of either kind, where asking `TorrentStreamingService` directly is empty for HTTP-backed debrid playback.
- Domain DTOs and port interfaces live under `src/domain/` in the `kinema::domain::` namespace (`Media`, `Library`, `Subtitle`, `Discover`, `Debrid`, `RealDebrid`, `AllDebrid`, `Download`, `PlaybackContext`, `Indexer`). `src/api/` holds only outbound HTTP adapters (`*Client`, `*Parse`, concrete indexers, `IndexerSelector`) in `kinema::api::`.
- Stream discovery goes through `domain::Indexer` (concretes in `api/`: `TorrentioIndexer`, `PeerflixIndexer`) selected by `api::IndexerSelector` from `config::IndexerSettings` (group `[Indexers]`). View-models / controllers receive an `IndexerSelector*` and call `selector->active()->streams(kind, id)`; per-indexer URL config lives inside each concrete indexer and reads from its own settings class (`config::TorrentioSettings` group `[Torrentio]`, `config::PeerflixSettings` group `[Peerflix]`). Stream-result filtering is universal client-side via `core::stream_filter::ClientFilters` (blocklist + exclusions); the Torrentio indexer additionally pushes the exclusions into its URL `qualityfilter=` segment as an optimisation.
- Load remote artwork through `image://kinema/<role>?u=<url>` so `ui::qml::KinemaImageProvider` and `ui::ImageLoader` handle caching; do not bind QML `Image.source` directly to HTTP URLs.
- Keep embedded-player code behind `KINEMA_ENABLE_MPV_EMBED` / `KINEMA_HAVE_LIBMPV`; the player chrome is QtQuick/QML in `dev.tlmtech.kinema.player`, with no QWidget overlays, Lua overlays, or IPC bridge.
- Follow Plasma theming in QML with `Kirigami.Theme` and `Kirigami.Units`; do not add custom palettes or hard-coded colors. Use `/home/tlm/Projects/Kirigami/` as the local Kirigami source reference.
- Custom icon-only QtQuick controls (e.g. the player `IconButton`) must set `Accessible.role`, `Accessible.name`, an `Accessible.onPressAction`, keyboard activation (Return/Space) + `activeFocusOnTab`, and a hover `ToolTip` carrying the same name. `QQC2.Button` / `Kirigami.Action` with visible `text:` derive their accessible names automatically. Player chrome QML uses `qsTr(...)` (Qt translation, no `KLocalizedContext`); the app shell uses `i18nc(...)`.
- Validate QML changes with the Qt6 linter (`/usr/lib/qt6/bin/qmllint -I build/qml <file>`), not the bare `qmllint` on PATH (that resolves to Qt5 and silently no-ops). Overriding a base type's `final` property (e.g. naming a `Menu` property `title`) is a fatal load error the C++ build will not catch — watch for `shadows final member`.
- Every QML context menu uses `KinemaMenu` + `KinemaMenuItem` from `src/ui/qml/components/menus/`; rules (labels, ellipsis, ordering, destructive styling, keyboard activation) live in `docs/MenuConventions.md`.
- Add tests with `ecm_add_test(...)` in `tests/CMakeLists.txt` and add the target to the fixture `foreach` at the bottom.
- Validate with `cmake --build build -j$(nproc)` and `ctest --test-dir build --output-on-failure`.
- Downloaded Lucide icons are available in `/home/tlm/Downloads/lucide-icons/icons/`.
- `src/core/` is split into sub-folders that share the `kinema::core::` namespace: `persistence/` (Database + `*Store` + `MediaCache`), `mpv/` (Player, PlayerLauncher, MprisMetadata, Mpv*), `io/` (HttpClient, HttpError*, Logging, CachePaths, IdleInhibitor, UrlRedactor), `util/` (DateFormat, DateWindow, Language, Magnet, MediaChips, Moviehash, StreamFilter, StreamTokens, TorrentioConfig). Include paths follow the sub-folder, e.g. `#include "core/persistence/LibraryStore.h"`.
- Logging is set up by `core::installLogging()` (called from `KinemaApplication::configure()`): rich pattern with ISO-8601 ms timestamp / severity / category / `file:line in fn` (warn+) and a rotating file at `~/.local/share/kinema/logs/kinema.log` (5 MB × 5, rotated on startup; suppressed under `QStandardPaths::isTestModeEnabled()`). Use the per-subsystem categories declared in `src/CMakeLists.txt`: `KINEMA_APP` (shell/lifecycle), `KINEMA_DB` (Database + `*Store`), `KINEMA_CONTROLLER` (`controllers/*`), `KINEMA_UI` (view-models, image loader, `services/StreamActions`), `KINEMA_PLAYER` (embedded mpv), `KINEMA_API` (`api/*Client`), `KINEMA_HTTP`, `KINEMA_TORRENT`, `KINEMA_DOWNLOAD`. Tune verbosity via `kdebugsettings` or `QT_LOGGING_RULES` (e.g., `kinema.db.debug=true`); `./scripts/run.sh` exports a sensible default unless `-q`/`--quiet` is passed.
