# Probe font

`IBMPlexSans-Regular.ttf` is the unmodified IBM Plex Sans Regular font from
https://github.com/IBM/plex/tree/master/packages/plex-sans/fonts/complete/ttf
(retrieved 2026-10-17). Redistributed under the accompanying `OFL.txt`.
The committed bytes are the fixture's initial offline font on native and WASM;
GPUI Web maps `.SystemUIFont` to this family. No font-service requests are used.
