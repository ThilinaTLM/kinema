# Kinema documentation

There are two kinds of document here:

- **[architecture/](architecture/README.md)** explains how Kinema is built and
  why: its principles, engineering decisions and constraints, and the strict
  design-system rules. It describes what *is*, and you should read it before
  making a design decision. Start with the
  [principles](architecture/README.md#principles). For any UI work, read the
  [design system](architecture/design-system.md).
- **[proposals/](proposals/README.md)** holds drafts of new ideas and designs
  that are not decided or built yet, plus the roadmap. Once a proposal is
  implemented, its lasting rules move into `architecture/` and the proposal is
  deleted.

The source code and its doc comments own the implementation details. These
docs describe rules and rationale, not code walkthroughs or test logs. For
build and check commands, see
[development](architecture/development.md).
