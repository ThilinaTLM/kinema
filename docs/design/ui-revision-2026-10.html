Rules
  • Opened with the pointer: nothing is highlighted. Opened with the keyboard (Enter, Space, ↓): the first row is highlighted.
  • Hover sets the highlighted row, and arrow keys continue from the hovered row. A row is never both "selected" and "hovered", so only one highlight shows at a time.
  • Fix this in the shared Menu widget, not just this one menu. That covers context menus and Select as well.
  • If any row has a leading icon, every row gets one (Quit uses a power glyph). In the new toolbar (below), Open local file and Refresh are also buttons, so the menu is mostly About and Quit, but the menu keeps them for keyboard users.
  • Remove the "…" suffix everywhere: Open local file, Settings, Play, Stop, Stop serving, Add, Open Settings, Storage settings, Mark season watched/unwatched. Progress text like "Loading…" or "Searching…" keeps its ellipsis, because it's a status message, not an action label.

Layout rules
  • One frame for everything: responsive gutters 20–48 px. The 1800 px cap is raised to 2400 px so 1440p and 4K windows use the full width. The right-hand At a glance panel fills the space that's empty today.
  • Hero columns: poster 160–240, story fills the rest (overview max 880), glance panel 280–380. Under 1100 px the glance panel moves below the story as a single row of tiles.
  • The "chips" row becomes a plain metadata line. Certification stays a small chip, and the duplicate rating chip is removed because ratings live in the glance panel.
  • Fact groups use fit_grid with cards of at least 260 px: three across on wide windows, stacked on narrow ones. A group is hidden when it has no data, and nothing shows "—".
  • Cast becomes portrait cards with photos (TMDB profile images, with an initials fallback) in a wrapping grid, with no carousel. Behaviour
  • Remembered (global, in settings): provider, quality bucket, sort and cached-only. Changing any of them saves it immediately and applies it to the next title or episode. The free-text filter is per visit and isn't saved. If the saved quality bucket has no streams for a title, the page shows All for that visit only, with a muted "No 1080p streams · showing all" note, and the saved choice stays as it was.
  • Columns: quality badges (resolution, plus HDR/DV) · release name in mono (2 lines) with parsed tags (codec, audio, languages, source tracker) · size · seeders · cache. The flag-emoji soup is parsed into language tags.
  • Debrid cache column only appears when at least one of Real-Debrid or AllDebrid has a stored token, and it only shows columns for services that have one. Cells show ⚡ RD, Not cached, Checking (with a spinner) or Unknown when the check failed. A failed check is never shown as "not cached". The cached-only switch is hidden when no token exists. See open decision D1: there's an API constraint.
  • Drawer (≥ 1280 px): single-click selects a row and fills the drawer, and double-click or Enter plays. Below 1280 px there's no drawer, and clicking opens the existing Play sheet. "Play with" defaults to a debrid service that has the stream cached.

Page order (series)

Season picker (wrapping grid, no carousel)
  • Tiles wrap like every other grid (fit_grid, at least 176 px). Each tile has a season poster thumbnail, the name, "22 ep · 2013", a 3 px progress bar (accent while partial, green with a check when complete) and a "Next up" marker. The selected tile has an accent border and tint. Specials come last, with a dashed outline.
  • Smart default: the opening season is the one holding the next unwatched episode (the first unwatched episode after the last watched one). If nothing is tracked, it's the first regular season. A season you pick explicitly is remembered per series and wins until you leave.
  • Many seasons: when the tiles need more than 2 rows, the grid collapses to 2 rows that contain the next-up season, folding away fully-watched seasons before it. "Show all N seasons" expands in place. No horizontal scrolling is needed, so there's no GPUI carousel risk.

  • The season header shows the season overview, when TMDB has one, beside the toggle.
  • Similar series is new. It uses TMDB recommendations for TV, with the same grid and Show more as Similar movies, and the section is hidden when the provider has nothing.

6 · Discover / Library: stable backdrop, smoother card hover

The backdrop stops recolouring on every hover. The card overlay eases in, staggers its content, and has a real exit animation. Use the controls to compare options.

Backdrop
Motion
Motion spec
  • Enter: the card lifts 3 px and gains a shadow over 220 ms (ease-out). The scrim fades in over 260 ms. Title, facts and synopsis rise 10 px and fade in, staggered by 30 ms each.
  • Exit: the same properties reverse over 200 ms, with no stagger. Exit is interruptible: re-entering mid-exit continues from the current progress, so nothing snaps or flickers (progress is stored per card, not restarted with with_animation).
  • Moving quickly across the grid gets a 60 ms hover-intent delay before the overlay starts. The lift still starts immediately, which keeps sweeps from strobing.
  • Reduced motion: every duration is 0.
  • Backdrop A: a static brand wash (amber at the top-left, faint violet at the bottom-right) on the canvas, identical in Discover and Library and never tied to artwork. Detail pages keep their per-title artwork hero.

D1Debrid cache checks (researched 2026-10-28).
Real-Debrid: instantAvailability now answers error 37 "Disabled endpoint", and there's no bulk replacement. A per-torrent probe is addMagnet → selectFiles → info → delete, about 4 calls per torrent against a 250 requests/min limit, and it writes to your account. Side-effect-free, in one call: GET /torrents (up to 5000) tells you which hashes are already in your account.
AllDebrid: POST /v4/magnet/upload accepts magnets[] in one request and returns ready: true/false per magnet, so it's a real bulk check. But it adds every magnet to your account. Uncached ones start downloading and count toward the 30-active limit, and each one must then be deleted individually. Side-effect-free: /v4.1/magnet/status lists your account's magnets in one call.
