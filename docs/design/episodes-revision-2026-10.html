1 · Hero action row

Every action uses one ActionButton primitive: 32 px tall, 6 px radius, the same fill and edge. Icon-only actions are 32 × 32 squares. Library state is a labelled toggle with a clear on state (accent tint + filled bookmark), not a tiny black icon.

2 · Seasons, season header and episode cards

There are three calm layers: season tiles, a season header with a hairline divider, and a grid of contained episode cards. Each card is a raised surface with 8 px radius, like the Discover poster cards, with its text inside the card. Watched state uses the same WatchMark as the hero, in accent colour.

3 · Image states, fallbacks and caching

The Thumb primitive renders four states from one resolved artwork state. Cards keep their size in every state.

  • Fallback chain: episode still → season backdrop → series backdrop → season poster (cropped) → placeholder with "E03". Season thumb → series poster → placeholder with the number.
  • Loading: if a fallback image is already in memory, show it blurred and dimmed under a pulsing skeleton (the combined look you suggested). Otherwise show a plain skeleton. Memory and disk cache hits render without a skeleton; the skeleton only appears after about 150 ms of real waiting.
  • Fallback: the substitute image, slightly dimmed, so it doesn't pretend to be the episode still.
  • Not available (404/410 or an undecodable image) is remembered on disk for 24 h, so revisits go straight to the fallback with no request. It is retried after the TTL, or immediately on Refresh. Timeouts and offline errors are never remembered on disk.

4 · Primitive components (reused, not duplicated)

ActionButton

Primary / Secondary / Icon variants, optional on state (accent tint), busy, disabled with reason. 32 px, radius 6. Used in hero, streams drawer and season header.

WatchMark

Pure glyph for None / Partial(fraction) / All; 16 or 20 px. Used inside WatchToggle, OverlayButton and SeasonTile.

WatchToggle

ActionButton + WatchMark + word + count. It replaces the pill toggle and is used for movie, series and season.

LibraryToggle

ActionButton with on/off/busy states and a filled or outline bookmark.

Thumb

Aspect-ratio media frame with radius. Renders ArtState (Ready / Loading{fallback} / Fallback / Missing) with a pulse skeleton and placeholder label.

OverlayBadge / OverlayButton

A contrast-safe dark backing for anything placed on artwork: chips (E03, Next up) and 28 px icon buttons.

MediaCard

A raised r8 container with subtle edge, hover lift and clipping. EpisodeCard = MediaCard + Thumb 16:9 + body.

SeasonTile, SeasonHeader

Composites built from the above. No ad-hoc colours: only palette tokens (accent, accent tint, raised, line.subtle, text tiers).
